# Morgonvägen

Ett morgonspel för små barn. Varje avbockad syssla (toa, kläder, frukost, tänder, overall, mössa, vantar, skor) flyttar barnets figur ett steg på vägen från hemmet till målet. Målet väljs under Inställningar: förskolan, lekplatsen i parken, skogen, mataffären, bilen eller farmor och farfar på landet. Solen går upp i takt med att sysslorna blir klara, och när alla är framme blir det fest.

## Kom igång
1. Öppna https://soederberg.github.io/curly-broccoli/ i Safari på iPad eller iPhone.
2. Skapa barnen i välkomstguiden (högst 4): namn, storlek, hud, frisyr, hårfärg, tröja, byxor, huvudbonad och skor.
3. Dela → **Lägg till på hemskärmen** (då startar appen i helskärm).
4. Kontrollcenter → **Skärmdubblering** → välj Apple TV.

## Dela med andra familjer
Under Inställningar → **Dela familjen** skapar du en länk som innehåller barnen, sysslorna och valt mål. Den som öppnar länken får samma uppsättning på sin enhet. Om enheten redan har barn frågar appen först.

## Bra att veta
- Allt sparas lokalt i webbläsaren på varje enhet. Listan nollställs automatiskt vid ny dag, eller med "Ny morgon".
- Under Inställningar kan du även lägga till egna sysslor med valfri ikon och välja vem som gör vad.
- Ljud och uppläst beröm (svensk röst) kan stängas av.
- Hela appen är en enda fil: `index.html`. Inga beroenden.
