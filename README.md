# Morgonvägen

Ett morgonspel för Sigge och Charlie. Varje avbockad syssla (toa, kläder, frukost, tänder, overall, mössa, vantar, skor) flyttar figuren ett steg på vägen från hemmet till förskolan. Solen går upp i takt med att sysslorna blir klara. När båda barnen är framme blir det fest.

## Så kör du den på TV:n
1. Öppna sidan i Safari på iPad eller iPhone.
2. Dela → **Lägg till på hemskärmen** (då startar den i helskärm).
3. Kontrollcenter → **Skärmdubblering** → välj Apple TV.
4. Tryck på bilderna på iPaden för att bocka av. Tryck igen för att ångra.

## Bra att veta
- Allt sparas lokalt i webbläsaren. Listan nollställs automatiskt vid ny dag, eller med "Ny morgon".
- Under "Sysslor" väljer du vilka sysslor respektive barn ska göra.
- Ljud och uppläst beröm (svensk röst) kan stängas av.
- Hela appen är en enda fil: `index.html`. Inga beroenden.
